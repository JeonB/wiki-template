# Wiki 시작하기

이 Wiki 템플릿에 오신 것을 환영합니다!

## 주요 기능

- **마크다운 기반 문서 작성**: 간단한 마크다운 문법으로 문서를 작성할 수 있습니다.
- **카테고리 및 태그**: 문서를 카테고리와 태그로 분류할 수 있습니다.
- **Git 버전 관리**: 모든 문서는 마크다운 파일로 저장되어 Git으로 버전 관리가 가능합니다.

## 사용 방법

1. **새 문서 작성**: 상단의 "새 문서" 버튼을 클릭하여 새 문서를 작성합니다.
2. **문서 편집**: 문서 페이지에서 "수정" 버튼을 클릭하여 문서를 편집합니다.
3. **문서 삭제**: 문서 페이지에서 "삭제" 버튼을 클릭하여 문서를 삭제합니다.

## 마크다운 문법

이 Wiki는 표준 마크다운 문법을 지원합니다:

- **제목**: `# H1`, `## H2`, `### H3`
- **굵게**: `**굵은 텍스트**`
- **기울임**: `*기울임 텍스트*`
- **링크**: `[링크 텍스트](URL)`
- **리스트**: `- 항목` 또는 `1. 항목`
- **코드**: `` `인라인 코드` ``
- **코드 블록**: ` ```언어 코드 ``` `

더 많은 정보는 [마크다운 가이드](https://www.markdownguide.org/)를 참고하세요.
